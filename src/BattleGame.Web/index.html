Báo Cáo Tài Sản Người Chơi

Bảng tổng hợp dữ liệu kết nối giữa các bảng Player, PlayerAsset, và Asset trong cơ sở dữ liệu BATTLEGAME.

Đăng Ký Người Chơi

Quy Cách Cấu Trúc API Endpoint

POST /api/registerplayer
{
  "playerName": "Player 1",
  "fullName": "Nguyen Van A",
  "age": "20",
  "level": 10,
  "email": "player1@battlegame.com"
}
Thêm trực tiếp thông tin người chơi mới vào bảng Player trong cơ sở dữ liệu MySQL / SQL Server.

Tạo Tài Sản Mới

Quy Cách Cấu Trúc API Endpoint

POST /api/createasset
{
  "assetName": "Hero 1",
  "levelRequire": 5
}
Thêm trực tiếp thông tin tài sản mới (Hero, vũ khí, vật phẩm...) vào bảng Asset trong cơ sở dữ liệu MySQL / SQL Server.
