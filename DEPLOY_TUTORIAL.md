# Hướng dẫn Deploy Azure Function lên Cloud

1. Truy cập https://portal.azure.com và tạo mới một Function App (.NET).
2. Mở dự án trong VS Code, cài đặt Azure Functions Extension.
3. Đăng nhập tài khoản Azure trong VS Code.
4. Nhấp chuột phải vào dự án -> chọn **Deploy to Function App...**
5. Sau khi deploy, truy cập Azure Portal -> Function App -> Configuration để cập nhật Connection String kết nối CSDL MySQL.
